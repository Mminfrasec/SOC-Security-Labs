## Working Standard

A published artifact must demonstrate a specific technical capability.

The minimum workflow is:

```text
Requirement
→ Design
→ Configuration
→ Testing
→ Controlled failure
→ Evidence collection
→ Diagnosis
→ Resolution
→ Validation
→ Documentation
→ Reproduction
```

A successful configuration without validation or troubleshooting evidence is incomplete.

Copied tutorials without independent analysis, failure testing, validation, or technical explanation will not be presented as original work.
